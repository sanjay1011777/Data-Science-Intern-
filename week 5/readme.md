# Customer Sales Analysis

## Project Overview
This project analyzes customer purchasing behavior and sales performance
using advanced Pandas data manipulation techniques. The goal is to identify
top customers, sales trends, and actionable business insights.

## Objectives
- Analyze customer purchasing patterns
- Identify top customers and regions
- Perform advanced data aggregation and filtering
- Create pivot tables for summarization
- Visualize sales performance

## Dataset
- sales_data.csv
- customer_churn.csv

## Setup Instructions
1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt
3. Run the notebook:
   customer_analysis.ipynb

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

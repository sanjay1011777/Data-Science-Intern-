# Weather Data Analysis

## Project Overview
This project analyzes historical weather data to understand
temperature trends and humidity distribution.

## Dataset
Source: Kaggle – Weather History Dataset

## Setup Instructions
1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt
3. Place `weatherHistory.csv` inside the `data/` folder
4. Run:
   python main.py

## Outputs
- Monthly Average Temperature (Line Chart)
- Humidity Distribution (Histogram)

## Tools Used
- Python
- Pandas
- Matplotlib
